## 📋 Overview
This repository hosts the master distribution packet (`5D-VOYNICH-FSM-ROOT-V1`) for reinterpreting the Beinecke MS 408 Voynich Manuscript not as an untranslated natural language text, but as an **analog, 5-dimensional finite-state machine (FSM)**. Utilizing a **144-node topological matrix**, this architecture executes procedural state transitions across herbal, astronomical, biological, and pharmaceutical folios.
